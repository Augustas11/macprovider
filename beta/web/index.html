What this proves: the request left your browser, hit a Vercel edge function, which forwarded it through the Cloudflare tunnel for the chosen Mac. A real local model on that machine streamed the answer back. TTFT and tok/s are measured client-side.

What it doesn't prove yet: the response isn't cryptographically bound to the model weights — only attested by the tunnel hostname. Signed receipts land in Phase 3.
