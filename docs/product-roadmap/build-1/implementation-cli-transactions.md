Implementation is in progress. This document is a coverage ledger, not physical acceptance.

CLI owns transaction UUID reservations, a private persistent journal, OS-held owner and existing adoption locks, five-second progress, cancellation markers, bounded preparation, exact signed primary artifact verification, refresh before atomic no-replace publication, interrupted-owner reconciliation, and separate measured result retrieval. Prepared recommendation uses the complete prefetched-artifact map and real recommendation engine. A child-side opt-in parent lifetime guard exits candidate-only no-join processes when their owning CLI dies. Manual no-join behavior is unchanged.

Explicit isolated configs use their own artifact/transaction roots and scoped HMAC/log files. Default config reads existing HMAC custody without creating or rotating it. Foreground provider conflicts fail closed; isolated configs also refuse unrelated managed operator providers. This is a safety refusal, not evidence that every provider lifecycle scenario completes.
