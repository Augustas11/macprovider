Distribution stream build

2026-05-28

Scope boundaries

Implemented only the SPEC-003 distribution stream: shell scripts, launchd plist template, GitHub Actions release workflow, README content, and this implementation note. No Swift, Go, beta, or spec files were modified by this stream.

Design choices

  • install.sh targets ~/macprovider and passes explicit CLI flags from launchd because the distribution build prompt superseded the older SPEC-003 ~/.local/bin example. The public installer no longer accepts an install-dir override because replacement installs remove the existing install directory.
  • The release workflow wraps the existing phase3-binary/dist/package.sh output and renames the asset to macprovider-cli-<tag>-darwin-arm64.tar.gz so the public installer can use the SPEC-003 release shape.
  • The launchd template adds __MODEL_ID__ because the prompt requires --model <MODEL> in ProgramArguments but did not list a model placeholder.
  • The root README.md did not exist in the checkout, so the stream created it with the requested Join the Network section instead of inserting into an existing file.

Deviations and open questions

  • OQ-1/OQ-5 code signing remains unresolved. The installer verifies a signed checksums.txt manifest and SHA-256 before extraction, then asks before running xattr -dr com.apple.quarantine. The embedded release signing public key placeholder must be replaced before public hosting.
  • The installer defaults MACPROVIDER_GITHUB_REPO to augstar/macprovider-poc. Operators can override this if releases move to a dedicated artifact repository.
  • Full AC-1 and AC-2 cannot be completed until the v1.2 binary and v1.1.2 coordinator stream are published and deployed.
