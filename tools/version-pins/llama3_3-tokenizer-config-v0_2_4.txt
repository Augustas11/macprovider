# Normative template structure for Llama-3.3 multi-turn tool calling (per public docs):
#
# - System turn delimiter: "<|begin_of_text|><|start_header_id|>system<|end_header_id|>"
# - User turn delimiter:   "<|start_header_id|>user<|end_header_id|>"
# - Assistant turn delimiter: "<|start_header_id|>assistant<|end_header_id|>"
# - Tool turn delimiter:   "<|start_header_id|>ipython<|end_header_id|>"
# - End-of-message marker: "<|eot_id|>"
# - Tool-call sentinel (assistant emitting): "<|python_tag|>" followed by JSON
#   with shape {"name": "<fn>", "parameters": {<args>}}
# - Tool-result rendering (provider injecting): plain JSON-stringified result
#   content inside the ipython turn body
#
# Implementation in phase3-binary/Sources/malibu-cli/ToolPromptRenderer.swift
# follows this structural contract. Golden fixture in MultiTurnTests.swift verifies
# the structural assertions: presence of <|python_tag|>, <|eot_id|>, ipython turn
# delimiters in the expected positions for a known multi-turn fixture input.
#
